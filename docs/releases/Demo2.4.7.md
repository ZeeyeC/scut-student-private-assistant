# Demo2.4.7：当前甲乙合并版本

本版从当前分支源码独立构建、验证并打包，不依赖任何历史 App 或 Demo2.2 基线。版本号保持 2.4.7，对应已合并的甲方规划核心和乙方交互；本次重新构建 App，不复制旧预览充当发布版本。

已包含：课程分段与冲突校对、重复约束、容量和真实方案比较、局部重排、显式日常候选；执行补记与更正、自愿计时、档案、目标、周复盘；持续对话约束、冲突批准门禁、目标共享容量、下周计划草稿、应用内无声建议、多轮规划协商和时长建议采纳界面。

## 使用

1. 打开包内“课间桌宠.app”，个人资料继续使用原位置；模型连接使用原设置。
2. “助手 → 安排持续约束”补充日期与钟点，查看真实预览并确认；已确认规则须明确停用。
3. “目标与复盘”核对共享容量、生成下周草稿，或在“一起调整计划”修改本轮条件、选择真实方案后确认。
4. “设置 → 主动建议设置”明确开启类别及安静时段；建议可以稍后、关闭或打开本人任务详情。
5. 时长建议生成服务尚未接入，界面不会虚构建议。正式安排依旧经草稿确认，打开任务、网站或文件不表示任务已完成。

## 归档与验证

包含 App、应用 ZIP、当前工作树源码 ZIP、使用说明、验证结果、完整日志、manifest、整理记录和 SHA256。发布脚本顺序构建当前 App，执行全部后端/前端/浏览器/原生和三组实际冻结后端检查，再检查签名、私密值与 ZIP 完整性。任何检查失败均保留暂存和旧归档，不覆盖同名发布版。

当前自动化使用隔离合成数据，没有付费模型调用。具体结果以本包“验证结果.json”、各检查日志和 manifest 为准；先前开发阶段的模型结果如被收录，会明确标为历史材料，不冒充本轮重新调用。
