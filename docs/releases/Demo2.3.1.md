# Demo2.3.1 使用说明

日期：2026-10-28；App版本2.3.1，Apple Silicon / macOS 13及以上。保留Demo2.3功能，本轮完成一项新增能力：**助手文字添加课表**。

## 使用

1. 先通过旧桌宠“关闭与退出 → 停止后台并退出…”关停旧服务，再打开本目录`课间桌宠.app`，或解压应用ZIP打开。也可使用源码目录的`campus-pet/启动课间桌宠.command`。
2. 在设置中核对学期名称、首周周一、周数、节次时间与统一模型连接。继续使用本机已有Key，不需要分别配置课表识别和助手。
3. 打开“助手”，或“课表 → 用文字添加课表”。例如：“添加高等数学，每周一第1、2节，第1至16周，教室A101”。多门课可以一起输入，每个不同星期/节次组合分别形成候选。
4. 不清楚周次等信息时可以先留空，助手会按缺失字段追问；例如继续回答“这门课是第3至8周”。补充会修改原草稿，其他课程保留。
5. 对照左侧原始消息逐门校对，确认学期，点“检查导入差异”，然后“校对完成，准备保存 → 确认保存”。只有保存后才进入固定课表，后续智能排程才能避开这些课程。

教师、教室和校区可为空。名称、星期、周次和节次必须补齐，配置需能确定具体上课时间；不猜全学期。草稿和问题可在刷新、重启后继续，完全相同的课程复用，已有课程保留。正式课程调课不通过新增同名候选代替。
