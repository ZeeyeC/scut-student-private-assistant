# Demo2.4 乙方独立功能开发预览

2026-10-29。应用版本字段沿用2.4.0，属于development-preview；正式版与旧预览保留。

本次新增自愿计时、偏好与精力档案、目标管理和独立周复盘，并修复断连取消时SQLite会话清理问题。详见[开发结果与待联调清单](../roadmap/demo2.4-b-independent.md)。

1. 在“今日”学习安排或任务步骤详情中，选择“开始计时”。可以暂停、继续；结束时单独确认执行反馈和任务状态。若有漏计，勾选改为手工补记会替代本次计时，不叠加旧计时。失联/重启后只保留已确认秒数，缺口由本人核对。
2. 在“设置 → 偏好与精力档案”编辑并确认时区、时段与偏好。空白保持未知，休息0分钟是明确值；可重置，课程任务保留。目前保存档案，尚未改变排程。
3. 在“目标与复盘”创建目标、填写每周预算、添加或关联现有子任务。可暂停/恢复，已完成事实保留。当前容量未知，保存目标不会自动新增安排。
4. 在同页选择周内日期和复盘时区，核对原计划、调整后计划、当前安排、已记录实际及历史估算。缺记录显示未知。可以写原因，接受/拒绝/恢复调整意向；接受意向还需后续排程联调，正式安排保持原样。

双击本目录“课间桌宠.app”。若旧后台缺少新增功能，先在旧助手设置停止后台，再重新连接；不要删除个人资料。开发调试时使用隔离资料，勿把已有数据或私密配置复制进交付目录。

目录应包含App、应用ZIP、源码ZIP、验证结果、日志、manifest和SHA256。正式发布预检因为缺少Demo2.2基线停止，本目录不替代正式发布。真实样本、甲方容量/重排/主动建议/多方案、真实用户完整操作仍待完成；具体结果以本目录验证结果为准。
