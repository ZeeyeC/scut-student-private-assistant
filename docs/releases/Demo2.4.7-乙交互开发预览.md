# Demo2.4.7 乙交互开发预览

对应本地分支 `codex/demo2.4.7-b-interaction`。这是从当前工作树新构建的开发 App，沿用甲乙候选版本 2.4.7；正式打包预检因缺 Demo2.2 基线被拒绝，不覆盖已有版本。

1. “助手 → 安排持续约束”：先写日期，缺钟点时保留待补充，补充后生成同一草稿，查看发生预览并确认。停用已确认规则需要第二次明确确认。
2. “目标与复盘”：核对目标共享容量；接受周复盘意向后生成下周草稿。按原计划确认入口保存，恢复意向不撤销日程。
3. 同页“一起调整计划”：明确日期、时段和本轮上限，保存意图并比较真实方案，再选择草稿确认。刷新可继续，取消保留旧事实。
4. “设置 → 主动建议设置”：明确开启、类别和安静时段。活跃应用内展示无声建议，可稍后、关闭、打开本人任务详情或生成重排草稿。
5. “步骤时长建议”目前显示生成服务未接入。未来甲产生符合契约的建议后，可核对样本并接受、拒绝或恢复原值。

模型连接仍使用原设置。打开网站/文件或任务详情不等于完成任务，自动建议和草稿都不自动改正式日程。

包内包括 App、应用 ZIP、当前工作树源码 ZIP、验证结果/日志、manifest 和 SHA256。真实样本验收、甲方尚未交付的消费/建议生成、Node 22 环境复核与正式归档仍待完成，详见 [开发记录](../roadmap/demo2.4.7-b-interaction.md)。

本轮自动验证：后端545项+18子断言、前端81项、浏览器49条、实际冻结包48项（15+17+16），原生逻辑与原生App重跑56项通过。首次原生健康超时证据保留，尚有环境间歇性限制。
