# Demo2.5 · 独立App与NaiWa桌宠

版本目标：2.5.0，日期：2026-10-30。开发分支：`codex/demo2.5-app-ui-naiwa`。发布完成状态以本版归档中的manifest与验证结果为准，不以这份说明代替构建结果。

## 本版变化

- 日常工作整合进独立App：今日、日程、任务、助手四项导航，设置分五组；主窗口和快捷面板共用同一套页面。减少常驻说明与大表单，编辑及校对按需打开。
- 今日保留下一项任务、近期安排和执行/计时入口；日程使用全部/课程/学习筛选，目标与每周复盘归入任务。任务、规划、冲突校对、草稿、建议和执行记录仍使用原真实API及明确确认。
- 外部浏览器只在学校课表导入时打开：指定Chrome，Edge可选并记忆。新增短期、绑定本次导入的回传授权，不要求浏览器拥有App会话；取消/过期/回传后限制继续访问，回App校对后才保存。
- 学习网站和资料链接在App中显示并复制；本机文件保留原文件打开方式。普通启动、旧菜单及WebKit新窗口不再自动打开完整浏览器工作台。
- 桌宠接入用户指定NaiWaChatPet固定提交的11个片段、219个帧引用。保留420×560比例、原始帧时序和七种业务状态；静态姿态保持800ms，惊讶按三段播放。透明点击和提醒肚皮区域与绘制共用几何变换，业务提醒/审批优先。
- 按需校验与解码、64MiB LRU缓存、隐藏/休息/减少动态效果控制；图标、默认帧和来源声明统一使用新素材。正式包检查拒绝合成QA资源与旧角色混入。
- 扩展更新为0.1.2：取消/过期/失败会按导入绑定代次停止采集，旧桥接不会清理新重试；旧扩展需更新后再打开学校页。主窗口切换快捷面板时，已挂载日历在周视图与列表间实际切换，保留日期。
- 修复首次本地启动的资料选择竞态、隐藏建议面板使用过期资料版本、规则刷新时仍可提交旧版本，以及抽屉交错后主界面锁定等问题，保留重现回归。

## 使用

打开本版“课间桌宠.app”。单击角色展开今日已安排任务环，左击气泡查看、右击完成；从桌宠菜单进入主窗口。设置中的课程与学期提供Chrome/Edge选择，日程→导入课表→学校课表进入导入引导。模型、资料和备份沿用原私有目录，不进入发布包。
