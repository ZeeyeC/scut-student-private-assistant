# Demo2.6.1 · 简洁多图作业对话

本版按已确认的chat-images-simple预览实施：日常仍使用独立App，主导航、课表浏览器导入、桌宠与个人记忆保留。

## 使用

把作业图片拖入聊天区、连续选择或粘贴，图片从输入框左上角按添加顺序排列、自动换行，可逐张移除。文字输入位于图片下方。单次最多5张PNG/JPEG/WebP，单张不超过10MiB或2000万像素。新添加的一批有无效图片时整批提示，已选择的图片保留。

不再显示图片发送授权勾选框和截图日期选择。用途轻提示位于输入区下方；只有点击发送后才上传，并交给你配置的模型识别，拖入和预览本身不上传。

识别结果直接显示在聊天区，按编号列出每项作业和截止日期。只对缺失日期给出一次可跳过的询问；可以自然语言回复“第一项周五晚上八点，第二项暂不填”，或直接“暂不填写”。不回答就保持未填写，不猜23:59，也不妨碍点击“确认保存N项”。“校对详情”按需展开完整原图、证据与编辑表单；展开时在详情内确认，避免简洁按钮忽略未保存的表单修改。

## 可靠性

多图逐张识别，全部成功后生成同一份待校对草稿，每项保留实际原图来源。部分失败时成功结果本地暂存，重试只处理未完成图片；取消阻止迟到结果产生草稿。不会在部分图片失败时直接保存不完整批次。不同截图内容重复时不擅自合并，请核对实际任务内容。

识别、日期跳过都不等于保存。正式任务只有确认事务成功才产生；旧单图客户端、历史图片消息、原有文字修改与审批继续兼容。截图中的相对日期缺少原消息日期时保持未知，不能拿上传时间冒充；后续文字补充才按该条消息日期与现有时间工具处理。

作业整理作为应用内assignment-intake Skill实现，只在当前图片请求或同会话仍有待校对图片作业时加载。程序保证归属、版本、来源、空日期、幂等、取消与重试边界；截图指令不得授权写入或长期记忆。

## 验证与分发

本轮使用隔离资料和确定性模型测试，不自动调用真实付费视觉或文字模型。真实自然语言提取、截图准确率和学校最终保存等既有真实样本缺口仍保留。发布是否通过，以本版manifest和验证结果为准。

每版独立从当前源码构建，包含App、应用ZIP、源码ZIP、说明、验证、manifest与SHA256；个人Key、配置、数据、备份和依赖保留，不自动推送GitHub。Antigravity完成多图后台与附件组件主要文件，首轮超时/前端流中断后缩小任务重试；主助手补接口和任务卡、审查、测试与发布，不以CLI返回成功字样代替实际验收。
