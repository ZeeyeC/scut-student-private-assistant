# Demo2.5.5 · 正常退出与资料路径记忆

Command+Q、Dock退出等正常退出先通过已认证接口停止当前后台，确认停止后退出。后台忙或失败会保留App并提示，不能强杀任意服务。高级“仅退出桌宠”仍保留后台。

升级启动通过--remember-data-dir明确记住经成功启动的资料目录及模式；后续双击沿用，显式路径优先。隔离smoke、新用户验收不会记住临时资料。原资料未迁移/删除。

本地旧版本集中到ProjectManagement/课间归档/历史版本，仅移动不删除；当前包、源码、配置、资料、备份与依赖保留。GitHub保留源码历史，不能替代私密资料或未远程备份的发布包。本版本不公开上传App或个人数据。

正式结果以manifest/验证结果为准；真实学校最终保存/准确率、OCR、多物理显示器和Windows/Intel既有缺口继续保留。素材声明随包保留。
