# Demo2.3.2 使用说明

日期：2026-10-28；App版本2.3.2，Apple Silicon / macOS 13及以上。在Demo2.3.1基础上完成一项功能：**一键生成当日日程**。

## 使用

1. 通过旧桌宠“关闭与退出 → 停止后台并退出…”关停旧服务，打开本目录`课间桌宠.app`；也可使用源码`campus-pet/启动课间桌宠.command`。
2. 核对设置中的时区、学习时段、每日上限和课程时间。先添加待办并补齐步骤与预计耗时；固定课表只决定占用时间，不自动产生作业。
3. 在“今日”或“待办与日程 → 智能安排”点击“一键生成当日日程”。助手中请求安排今天也调用同一规则服务；不需要额外模型配置。
4. 查看今天的课程、事项、禁排、学习建议、变更数量及未安排原因。程序只使用今天剩余时间，避开固定课程与事项、已确认禁排及锁定安排，遵守依赖、截止时间和学习上限。
5. 点击“校对完成，准备保存 → 确认保存”才写入正式日程，确认前现有日程保持原样。刷新或重启可继续查看草稿和已保存结果。“智能安排未来7天”仍在待办与日程中保留。

## 边界

已开始、已完成、锁定及其他日期的安排原样保留；其他日期不在当日预览中展开。有冲突的保留项会提示核对，不计作有效新分配。未来已预留的工作不会在今天重复安排；已结束而未记录完成的块仍保留为历史，不自动计为完成。细分实际投入和未执行原因仍待T10实现。

排不下的工作显示剩余分钟数与原因，不自动延至明天、不更改截止日。没有任务、步骤或耗时会说明，不凭空增加复习。资料在校对期间改变、开始时间已过去、待替换块已开始或跨本地午夜时，确认会拒绝并要求重新生成。

原有文字课表、图片/PDF校对、桌宠气泡、静默变色提醒和统一模型连接保留。本版不代表原任务书全部完成，真实华工课表30份/5布局/95%字段准确率仍待验收；学期例外、跨校区冲突、个性化与自动重排按后续任务继续。
