# Demo2.4 使用说明

日期：2026-10-28；App版本2.4.0，Apple Silicon / macOS 13及以上。继承Demo2.3.2，本次新增**单次调课、停课与恢复原课**，按用户要求完成此项后停止。

## 开启与使用

1. 在旧桌宠“关闭与退出 → 停止后台并退出…”关停旧服务，再打开本目录`课间桌宠.app`。源码`campus-pet/启动课间桌宠.command`也会优先打开本版。
2. 在课表或待办与日程点击具体课程，选择“调课或停课”。界面显示原课日期，只影响该日期对应的一次课程，其他周保留。
3. 选择调课并填写新起止时间/教室，或选择“本次停课”；填写教师、教务通知等调整依据，点击“预览课程调整”。时间按设置时区录入，跨周、跨午夜可表达，不猜学校校历。
4. 核对调整前后、冲突及受影响的学习安排，再“校对完成，准备保存 → 确认保存”。确认前课表保持原样。重叠会提示，真实课程事实仍可确认；已保存学习安排和锁定项不会被移动，需重新生成计划并确认。
5. 在课表“已确认课程调整”选择“恢复原课（先预览）”，核对后确认即可撤销；记录保留，展开“查看调整记录”可查每次依据和前后时间。草稿、记录和结果支持刷新、重启、导出与备份。

图片/PDF扫描、助手文字添加课表、手工/空白格录课继续保留。待办需有步骤及耗时，今日页或待办与日程可“一键生成当日日程”，仅安排今天剩余时间，预览后确认；原有未来7天规划保留。统一模型连接使用现有本地配置，不增加Key。

## 边界与资料

这是T02的单次课程例外首版。完整学校节假日/实践整周规则、连堂休息/非连续节次完整展开、跨校区耗时冲突、个性化和自动重排仍待开发。程序不会凭公共节假日推算学校补课，不把固定课程自动变成作业。真实华工课表30份、5布局、95%字段准确率仍未验收，版本打包不代表任务书全部完成。

调整按原课程ID/日期定位，同一发生不重复生效；跨周移动和撤销均保留课程固定周次、原发生ID、所有学习块和完成记录。例外改变后旧计划因版本过期不能确认。调整草稿与预览绑定，需改内容时删除并重新生成。课后询问和提醒跟随生效课时；原时段已配置的快捷方式需在新发生时间核对设置。

App、应用ZIP、当前工作树源码ZIP、说明、日志、检查报告、manifest、整理记录和SHA256均在本目录。Demo2.2及其他正式版本保留，验证成功后仅清理构建与测试缓存。Key、个人资料、备份和依赖不打包或删除；源码目录保留原名以兼容旧App资料路径。本机沿用现有配置/资料，异机使用独立Application Support目录。App使用本机临时签名，尚未公证。
