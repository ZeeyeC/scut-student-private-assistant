# Demo2.4.8 · 甲乙规划接通版

基于乙方Demo2.4.7联合交付，完成甲方后续任务 A-01～A-05 的核心接线：真实执行与更正直接进入排程，变化事件生成可恢复的重排建议，已确认个人档案和目标周预算参与实际分配，同一步骤的可靠执行记录可生成时长建议。

## 使用

1. 打开“课间桌宠.app”；旧资料路径和模型设置保留。
2. 在“待办与日程”查看容量、规划风险和“查看执行、档案和目标依据”。未知与0、旧估算与真实投入分开展示。
3. 日程界面打开、回到前台及活跃期间每30秒合并检查变化，可忽略或生成重排草稿；正式保存仍需原有校对确认。锁定、完成、已开始和未结束计时关联的安排保留。
4. 在原设置确认学习偏好、精力、专注/休息、日负荷、休闲及复习间隔；偏好方案使用适用字段，普通任务缺少类型的偏好会明确显示缺口。复习候选分钟仍由你指定。
5. 在“目标与复盘”关联真实任务，设置预算和reduce/delay/ask。各目标共享同一容量，不重复排同一任务，不擅自改截止日。暂停目标的原有独立任务仍可排程。
6. 在同页“步骤时长建议”点击“检查并生成时长建议”。需同一步骤至少3条可靠执行及末次完成反馈，才会建议预计总量；先校对后接受，拒绝/恢复继续使用乙原消费流程。
