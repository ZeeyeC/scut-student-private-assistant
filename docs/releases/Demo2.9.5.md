# Demo2.9.5 课程作业补记

- 自动课后作业询问只检查学期时区的当天。过去日期退出自动队列，午夜仍打开的自动表单关闭，已输入内容保留为可恢复草稿。
- 日程 → 对应日期 → 点击课程 → 补记作业。课程详情显示作业内容、可选预计用时及截止时间；生成草稿后校对确认，正式任务会显示在该节课详情和任务列表。
- 可从课程详情主动查看当天课后草稿。来源日期与截止时间独立，不填写截止时间时保持待补充。
- 助手工具支持查询课次并生成关联该次课的作业草稿。引用使用真实课程及原课日期，保存前重新核验停课和调课；需用户校对确认。
- 明确预计用时的作业同时建立完成步骤；单次课补记不会自动安排学习，可从课程详情选择“安排学习”。原课后表单的保存并排程流程继续保留。
- 同一课次已记作业会退出相应待填写范围；重复确认和保存响应丢失重试不会重复创建任务。已保存作业保留课程来源快照。
