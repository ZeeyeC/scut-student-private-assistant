# Demo2.4.7 甲乙联调开发预览

2026-10-29。分支`codex/demo2.4.7-ab-integration`，应用版本2.4.7，标记development-preview。当前目录是联合候选，不替代任何正式版。

甲方的课程分段、冲突、重复约束、容量、方案比较、局部重排、作息候选和风险计算，已与乙方的实际执行、计时、更正、档案、目标和周复盘合并。完整接点和剩余消费适配见[联调检查](../roadmap/demo2.4.7-ab-integration.md)。

1. 双击本目录`课间桌宠.app`。若旧后台缺少联合能力，先在旧助手设置停止后台，再重新连接；无需删除个人资料。
2. 在“今日”或任务步骤详情补记/计时，独立确认本次结果和整项任务状态。更正保留原记录。暂停、失联与改补记规则沿用乙方版本。
3. 在“待办与日程”查看实际容量、“安排有变化？”和“比较安排，再做决定”；生成后仍需校对确认，单纯查询不移动日程。计时未结束时不能删除其关联安排，先结束或放弃计时再重新生成。
4. “设置”里的偏好档案、“目标与复盘”里的目标/周报可独立使用；档案尚未参与甲方排序，目标容量页尚未接入，复盘接受意向尚未应用下周安排。手动软偏好编辑器可影响甲方方案，不等同于档案已接通。

联合自动化验证用隔离合成资料与固定模型，没有自动调用付费模型或操作个人数据库。真实样本、直接权威执行/事件消费、档案/目标适配及T13–T15完整交互仍需后续开发联调。

目录应包含App、应用ZIP、源码ZIP、验证日志/结果、manifest与SHA256。正式发布预检因缺少Demo2.2基线停止，本预览保留验证与失败证据，不覆盖原有发布包。
