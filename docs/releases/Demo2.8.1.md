# Demo2.8.1 · 多版本启动交接修复

修复先开旧桌宠、再开新版时停在连接失败页面的问题。原有2.8资料、语义检索和Zotero能力保留。

- 新版检测到不同资料目录或旧构建后台时，说明冲突并提供“切换到此版本”和“取消”。显示当前将使用的资料目录，切换不合并、不覆盖两边资料。
- 切换先请求旧窗口正常退出；孤立后台通过其既有本地会话、CSRF和空闲检查优雅停止。忙碌、服务身份变化、非课间服务或拒绝退出均停止交接，不强制杀进程。旧版本未选定资料时请先在旧版本中正常退出。
- 相同资料也必须匹配运行构建身份，防止新版界面复用不含新功能的旧后台。同一构建重复打开继续激活已有窗口，不同版本不再静默唤起旧版。
- 未连接成功且未在启动的窗口可按Command-Q退出，不向另一份资料后台发送停止请求。
- 首次升级后，请固定使用最新目录的App；已验证的历史版本归档到私有GitHub Releases，可按云端归档索引恢复。

## 验证

本版从当前源码独立构建，以本版manifest、SHA256和验证结果为准。针对回归覆盖旧构建、不同资料、非助手服务、忙碌拒绝、过期切换、CSRF/cookie、204会话兼容、HTTP重定向拒绝和无连接退出。实际旧2.5.4孤立后台使用正常停止接口恢复，无强杀、不删除个人资料、不调用模型。

本版不提高或宣称真实OCR、真实Zotero个人库、付费模型效果的既有验收范围。macOS Apple Silicon为实际打包平台。
