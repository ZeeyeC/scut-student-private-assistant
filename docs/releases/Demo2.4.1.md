# Demo2.4.1：课表分段与正确利用空档

本版在Demo2.4上完成甲的首项核心功能：非连续节次分段占用、连续节次的授课与休息分别表达。图片/文字课表校对支持非连续节次，排程按实际占用组避让，保留中间未上课节次的可用空档。

## 怎么使用

1. 在设置中核对学期日期和真实节次起止。课表可手工添加`1,3`，也可导入图片、PDF或用文字建立草稿，校对后保存。
2. 课表会显示两段课程。点课程可查看实际授课与受保护课间；相邻节次间的休息不会自动塞入任务。
3. 在今日生成当日日程，或在待办与日程生成未来7天方案。未上课节次的空档可用于真实待办，仍遵守缓冲、禁排、锁定、耗时、依赖和截止时间；预览后确认才保存。
4. 调课/停课作用于所选原日期的全部节次。仅换教室且起止不变保留原分段；新起止时间改变时按用户填写的一个连续新时段处理，不猜新课间。可在调整记录恢复原课。

原有无声紫色提醒、快捷打开、任务环和动画保留。连续授课组课间结束不重复提醒，非连续后一组独立提醒。课后作业仍在最后一节课结束30分钟后、打开或唤出App时询问。

## 升级与资料

新增区间字段从现有课程和设置实时计算，不删除或迁移个人课程、待办和模型连接。已确认日程、锁定和完成事实保留，不自动重排。升级前未确认的旧规则计划或课程调整草稿需重新生成并校对，原确认回执仍保留。

本版使用同一模型网关与本地私有配置，不新增Key入口。发布验证使用隔离合成数据和固定测试模型，不自动调用付费服务。保留Demo2.2和已有正式版本；新包验证成功后清理明确构建缓存。
