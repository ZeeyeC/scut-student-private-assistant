# Demo2.5.3 · 重新导入与覆盖课表

2026-10-31，macOS Apple Silicon，分支codex/demo2.5.1-ui-refinement。

学校导入在已回传、过期、失败或结束后提供“重新导入”。重新开始会取消仍有效的旧导入及其草稿，过期草稿不再作为待确认内容展示；浏览器启动失败的重试复用新会话。进入学校个人课表后仍需选择学期并点击“查询”。

课表校对页新增“替换当前课表”，默认关闭。开启后，准备保存会明确展示移除旧课程及本次条目数量；最终确认后，以本次结果替换全部已保存课程。未出现的旧课程会移除，相同来源课程复用ID。被移除课程的调课/校历撤销入口停用，历史记录保留；相关待办保留原课程名称快照，解除失效课程关联。待办、固定事项和个人资料保留；图片/PDF/文字原有合并流程不改。空捕获不能清空课表。此操作覆盖范围是当前全部课表，不支持按学期筛选覆盖。

修复空课表也报“另一端更新”：学校草稿创建后设置版本变化，旧校验曾拒绝已重新检查的保存。现在有新冲突预览token时按最新设置/课程/固定事项/例外校验；预览后数据又变仍拒绝保存，并保留编辑让你重新检查。无token旧客户端保留原保护，覆盖必须有预览。切换模式或编辑内容后重新检查。

本版沿用Dock、菜单栏、GUI和内置扩展。发布从源码独立构建，旧包保留，不自动覆盖个人真实课表；验证使用隔离资料，不调用付费模型。最终发布结果以manifest和验证结果为准。

真实学校曾完成23条安排回传，尚未完成用户最终校对/保存验收；OCR基准、多物理屏、Windows/Intel及原任务筛选计数Minor仍未关闭。素材来源声明随包保留。
