# Demo2.5.4 · 校区节次快捷选择

按用户提供作息增加五山、国际、大学城三个选项。国际与大学城时间一致但保存独立选择；12节时间以用户提供表为准，课室开放/课间操仅作说明。

导入前不显示选择器。学校、图片/PDF、文字课表校对中，在课程列表之前选择校区并展开只读作息；这里没有自定义时间编辑。选择只暂存，冲突预览按所选时间计算，确认保存课程才同时保存节次及校区。取消不写设置。设置→课程与学期在自定义节次之前提供同样选择，手改时间后标为自定义，保存后生效。

一张课表使用一套全局作息，不自动推断混校区，不修改课程校区/教室字段。旧自定义不自动覆盖，日程、排程共用已保存映射。保留覆盖导入、Dock及桌宠GUI。新版本独立源码构建，不自动确认真实课表，不调用付费OCR。真实学校最终保存/准确率、物理多屏和Windows/Intel仍未完成验收；旧任务筛选计数Minor仍保留。素材声明随包保留。

实现由Antigravity CLI的gemini-4-argon-medium、effort medium生成，主助手检查验证并打包。正式结果以manifest/验证结果为准。
