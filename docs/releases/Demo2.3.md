# Demo2.3 使用说明

发布日期：2026-10-28；App 版本：2.3.0。基于 Demo2.2 与两批后续开发代码整理打包，适用于 Apple Silicon、macOS 13 及以上。

## 打开与关闭

1. 若旧桌宠仍在运行，先通过其“关闭与退出 → 停止后台并退出…”关闭，避免继续复用旧后台。
2. 双击本目录的 `课间桌宠.app`；也可解压 `Demo2.3-Mac-AppleSilicon.zip` 后打开。
3. 点击桌宠查看今天已安排的待办气泡；左击气泡查看详情，右击完成。完整网页界面可访问 `http://127.0.0.1:5173/`。
4. 关闭时通过桌宠菜单退出；需要一并关停服务时选择“停止后台并退出…”。

App 内含运行所需的后端，不要求另装 Python/Node。此包使用本机临时签名，未做开发者公证。不要同时运行 Demo2.2 与 Demo2.3。

## 相比 Demo2.2 新增

- **单次禁排时段**：在“待办与日程”设置不能安排任务的时间，支持启停。新生成的计划避开启用中的禁排时段；锁定任务冲突会明确提示。规划草稿增加调整原因、变更比较与批准快照。
- **华工图片/PDF课表识别首版**：支持 PNG/JPEG/WebP、文字 PDF 与扫描 PDF，保留原件、逐页显示证据。识别结果先形成草稿，逐门校对、补齐未知字段、确认学期并预览新增/复用差异后才保存。原手工录入、空白格添加和网页扩展导入保留。
- **统一模型连接**：助手聊天、任务拆解、作业识别、课表识别共用模型配置和 Key；可设置文本/视觉模型与系统代理开关。已完成 DeepSeek 的五项真实接口联调。
- **资料完整性**：课表原件与渲染页纳入备份、导出和删除；重复上传或确认有幂等保护，中断识别不会自动重试付费调用。

## 首次使用新功能

在“设置”核对学期名称、首周周一、周数和节次时间；在“统一模型连接”核对服务地址、Key 和支持图文的视觉模型。在“课表”选择图片/PDF、同意发送至模型服务后识别，再对照原件完成校对。

图片限制为 10 MiB / 2000 万像素；PDF 限制为 20 MiB / 1–10页，加密或损坏文件明确拒绝。每页识别超时 120 秒，任一页失败不会保存半份课表。非连续节次暂需拆分手工添加。

## 资料和旧版本

本机开发目录仍叫 `scut-student-private-assistant-demo2.1`，它是持续维护的源码目录，名字保留以兼容现有数据和启动路径。App 在本机继续使用该目录的 `.env`、`data/` 与 `backups/`。这些个人资料、Key 和依赖环境均未打入发布包或源码 ZIP；请保留开发目录。

在另一台机器上运行时，原开发目录不存在则使用用户 Application Support 下的独立资料目录，需要自行配置模型。Demo2.2 保留原样，其 App、源码、演示视频及校验值不变。新旧版本在本机可能共用资料；如需回退，请先从设置导出资料或停服备份。

## 验证和边界

本次发布脚本重新运行后端/脚本测试、前端测试、浏览器流程、原生逻辑、54项原生集成检查，以及实际打包后端的 PDF 上传/渲染/导出/删除检查；具体结果见同目录日志、`manifest.json` 与检查报告。`DeepSeek联调-开发阶段.json` 是开发阶段的真实联调记录，打包没有再次发起付费请求。校验 ZIP 可用 `SHA256SUMS.txt`。

**Demo2.3 是当前功能的版本归档，不代表五层任务书全部完成。** 尚未完成30份真实华工课表、5种布局、逐字段95%准确率验收；当前仍需人工校对。调课/停课/实践周、跨校区冲突、个性化偏好、自动重排与执行复盘仍待开发。此版本没有新增录屏或上传 PR。

## 后续发布

每版开发完成后更新 `campus-pet/VERSION`、对应 `docs/releases/DemoX.Y.md`，运行 `backend/.venv/bin/python scripts/release-macos.py --version X.Y.0`。脚本重新构建并验证 App、生成应用和源码 ZIP、检查私密文件与校验值，再清理明确的缓存和旧开发预览；失败时保留之前版本与隐藏暂存目录。工作规范见源码 `AGENTS.md` 与 `docs/releases/发布流程.md`。
