# Demo2.9 · 课程资料工作区

课程资料从助手和设置中独立出来。左侧助手单独置顶，下方依次为今日、日程、任务、课程资料，设置固定底部；只内容区域滚动。

## 使用

- 打开「课程资料」查看全部保存文件和网页来源，按课程/未分类筛选、搜索文件名、按上传时间/名称排序。已有资料原位复用，无需重传。
- 「上传资料」选择所属课程后选取或拖入文件；单次最多5份，每份20 MiB，支持PDF、DOCX、PPTX、XLSX、TXT、MD。部分失败可重试，成功项不重复入库。
- 点击文件查看解析原文与位置，修改分类或删除。课程已移除、旧文件大小或日期未知时如实提示。
- 「用这份资料提问」打开助手并选中资料，由本人点击发送后才发给配置的模型。助手保留轻量「选择资料」入口。
- 网页保存和正文检索位于列表下方折叠区域；正文检索同样遵循课程或未分类筛选。

## 技术与数据

沿用React/TypeScript、TanStack Query、FastAPI、SQLite/SQLAlchemy及Swift/WKWebView，不新增运行框架或远端存储。摘要列表不返回全部正文或内部路径；分类以所属校验、revision、幂等键与隐私代次保护，原件保持原位。

## 验证范围

以本版独立构建的manifest、验证结果、SHA256为准。设计对照覆盖新资料页/侧栏及旧页面正文/桌宠；回归包括跨页迟到请求、分页删除、失响应重试和未分类检索范围。

使用隔离合成文件验证，不调用付费模型；不据此提高真实课表、作业识别、个人Zotero库或模型回答准确率的既有验收结论。实际平台为macOS Apple Silicon。
