# Demo2.4.3：每周重复禁排

基于Demo2.4.2，完成甲负责的下一项基本功能：每周固定安排可以重复占用时间，并由今日及未来7天排程统一避让。按用户要求以功能完整为主，不扩展乙负责的执行、档案和对话逻辑。

## 使用

1. 在「待办与日程 → 禁排时段」点击「添加禁排时段」。重复方式选择「每周重复」，填写生效开始与结束钟点，勾选星期；可填截止日期，留空长期有效。跨午夜把结束填为次日。
2. 生成草稿，查看指定起日后14天的实际发生时间，以及这个范围内重叠的已有安排。校对并确认后生效。
3. 生成当日或7天日程，新安排会避开每次禁排。已有任务与课程不会自动移动，预览并确认新计划后才替换可调整部分；锁定和完成事实保留。
4. 可修改整条规则或停用；停用后再启用，仍按原规则生效。旧版单次禁排继续可用。

## 验证与兼容

新增13项后端合成场景和2条浏览器流程，覆盖星期/期限、跨午夜、时区时差、预览只读、后续周排程、锁定、版本过期、编辑、停用与重启。全量结果以本目录日志和manifest为准，实际冻结后端另验证下一周禁排耗尽空档、列出受影响安排、正式计划未被静默改动。

旧单次资源无需迁移；重复规则按查询区间动态展开，不创建无限日历记录。复用原草稿、确认、幂等、版本与事件。排程规则升级为weekly-constraints-1，未确认旧计划需重新生成。接口供乙T13复用，见 `docs/roadmap/a3-weekly-constraints.md`。
