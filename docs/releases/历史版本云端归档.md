# 历史版本云端归档与恢复

本轮用户明确要求本地仅保留最新版，历史版本放到既有私有GitHub仓库。源码继续使用Git分支；完整历史App、安装包、源码快照、说明和原验证材料使用Releases附件保存。

## 查找与恢复

仓库：[ZeeyeC/scut-student-private-assistant](https://github.com/ZeeyeC/scut-student-private-assistant/releases)。历史版本标签形如`archive/demo2.8-20261102`，标题明确标注“历史归档”。需要有该私有仓库的访问权限。

登录GitHub后打开对应版本，下载完整归档ZIP并解压即可恢复原目录。也可用已登录的GitHub CLI：

```sh
gh release download archive/demo2.8-20261102 --repo ZeeyeC/scut-student-private-assistant --dir ./课间历史恢复
```

这里恢复的是历史程序和开发材料。个人课表、聊天、模型配置及本地备份保存在原资料目录；恢复旧App不会回滚或恢复某天的个人资料。

归档的SHA256、远端附件名及核验状态以[云端索引](历史版本云端归档索引.json)为准。完整ZIP已上传并重新下载逐字节摘要核对后，才允许清理相应本地副本。版本自身的验证范围仍以归档内原manifest为准；本轮归档不等于重新验收所有历史功能。

## 本地保留范围

- 最新正式App、最新应用ZIP/源码ZIP、说明及验证材料。
- 两个原有源码目录、开发任务书与Git历史，保持目录原名。
- 个人`.env`/`model.env`、课表/任务/对话资料、私有连接凭据、备份及已安装开发依赖。
- 轻量云端索引与恢复说明。

上述个人配置与资料不进入云端发布附件。历史诊断日志在单独“Diagnostics 历史归档”中，不代表成功发布；可重建的失败App二进制在新版通过后清理。
