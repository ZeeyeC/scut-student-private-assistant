# Demo2.8 · Zotero文献助手

在正式2.7的资料、网页、中文语义检索基础上增加Zotero只读文献助手。日常仍在独立App中使用。

## 使用
设置 → 模型连接 → Zotero文献库。默认关闭，不自动连接文献库。

- **本机Zotero**：先安装并打开Zotero，在其设置→高级允许其他本机应用通信；在课间启用并保存，点击测试连接。App内置MCP服务，无需Python、Node或终端配置。不安装上游Zotero插件，不读取个人Zotero SQLite、其他助手配置或密钥，不启动上游自动索引/模型下载。
- **已有MCP服务**：选择远端模式，填写HTTPS地址或本机HTTP回环地址；需要时输入访问令牌。地址不含账号、查询参数或片段。令牌空白保留，切换地址时空白令牌不沿用旧服务；可明确清除令牌。
- 连接后在助手中问“帮我找Zotero里的微积分论文”“读取这个条目的全文/笔记”。助手能搜索自己的文献库、读论文信息/摘要/附件全文索引、笔记、批注和文献分类，并按实际条目标题/key注明来源。文献内容按需发送给已配置模型，不能自动成为记忆或写入待办；生成任务仍走原有校对与确认。
- 内置MCP仅暴露6个只读工具，Agent只获得3个受限入口，不提供新建、修改、删除文献。读取文字每次有界，截断结果不能当作读完所有论文。

## 数据与连接
访问令牌在所选资料目录的data/.connector-secrets中按所有者独立保存（600权限）；不在SQLite、导出、回执、源码包或安装包保存明文。凭据绑定目标地址和配置版本，崩溃后不匹配的凭据不会发送。连接切换/关闭、清空资料使旧读取结果失效；同次笔记/批注固定一个连接快照。清空个人资料也清除连接凭据；备份/导出不包含令牌，恢复后需重新填写。

当前只支持本机个人模式使用文献连接。远端服务应由本人信任和配置；App不会安装、托管或代管远端服务。测试连接会实际读取一项文献分类用于核对连接，单纯打开设置不会连接。

## 技术
Zotero MCP Server0.15.2、FastMCP3.4.11、Pyzotero1.14.0、MCP SDK1.x和langchain-mcp-adapters。App内启动标准管道子进程，独立临时HOME，受限工具服务器不运行上游后台更新。开源许可随App的OpenSource目录保留。原2.7功能与本地模型按需准备保持可用。

## 验证与限制
正式构建结果以manifest和本版验证记录为准。真实MCP通信对合成Zotero HTTP服务的检索/题录/索引全文/笔记/批注通过；自动化不读取真实个人库、不调用付费模型。本机未安装Zotero，真实个人文献库和不同Zotero版本的外部样本尚待连接验收，不能用模拟结果替代该结论。Windows/Intel与所有PDF布局不作已验证承诺。
