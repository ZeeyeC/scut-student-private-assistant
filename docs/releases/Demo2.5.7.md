# Demo2.5.7 · 聊天作业截图闭环

聊天附件菜单提供“图片识别作业”和“导入课表”。作业图片支持文件选择、拖入聊天区和粘贴，单张PNG/JPEG/WebP、10MiB/2000万像素内；先预览，可移除并补充说明，确认图片发送授权后才上传并调用视觉模型。可单独发送图片；截图消息日期可留空，不把上传日当作截图日期。

识别复用原有作业草稿与校对界面，原图/证据保留；聊天可补充修改原草稿的指定项目，确认后才保存成任务，再沿用现有拆解和排程功能。图片、识别任务、会话及草稿有持久关联；上传/发送使用稳定幂等键，识别失败或服务重启中断可明确重试，取消阻止迟到结果成为可保存草稿。新会话不继承待发送图片，也不显示其他会话的图片草稿。

不新增依赖、不升级UI组件库：保留assistant-ui聊天运行时与输入框；为单图整批拒绝、显式授权及上传/发送响应丢失恢复，使用统一受控附件状态和标准文件拖放/粘贴事件。安装版内置Dropzone默认逐个接受多图，不直接用于本版单图策略。课表仍使用既有默认浏览器导入。

针对性回归及修复后的完整候选原生检查通过；系统选图/合成识别/修改/保存已在实际App验证，访达拖入与原生截图粘贴预览由用户确认通过。最终正式全量发布结果待生成。本轮不自动进行真实付费视觉调用，合成截图不等于真实截图准确率验收。

长期记忆/个人资料工具接通留下一版，计划书B–D未实现。本版保留原学校最终保存/准确率、OCR样本、多物理屏、Windows/Intel等既有缺口；不自动上传源码、验证材料或App。个人数据、模型Key、配置及旧扩展目录保留。

流式文字直接显示已收到的内容，关闭依赖动画帧的装饰性打字效果，避免WebKit后台帧暂停时一直显示占位。原暂停帧回归失败证据保留，修复后通过。
