# Demo2.7 · 资料、联网与语义检索

基于2.6.1。独立macOS Apple Silicon App，日常不需浏览器；学校课表导入仍按设置唤起Chrome/Edge。

## 使用
- 助手附件新增“课程资料”：PDF/DOCX/PPTX/XLSX/TXT/MD，最多5份、每份20MiB。选择/拖入仅在本地预览，点发送后解析、入库及交由所配置模型使用；图片原流程保留。
- 助手“课程资料”及设置→资料与备份可查看、检索、删除、关联课程和保存公开网页；可跨会话选用。PDF保留实际页码，Office转换保留段落定位，回答由工具给出来源。扫描件无可读取文字时提示转换或使用作业图片识别，不假称OCR成功。
- 助手可读取公开网页链接；后台读取不唤出浏览器，不支持需登录的动态页面/私网地址。公网校验、固定IP、每次重定向检查、限时限量；Fake-IP网络通过HTTPS DNS取得真实公网地址，不直接访问198.18占位地址。该解析会把待访问域名发送给Google公共DNS。
- 设置→模型连接→检索设置可填写自己的SearXNG服务，测试连接、保存或清空。未配置时明确提示；网页链接读取独立可用。App不内置或托管搜索服务。
- 本地语义检索可显式准备BAAI/bge-small-zh-v1.5中文模型并开启。下载模型无需付费模型API；索引使用Qdrant本地模式，权重按需下载，离线推理。未准备/关闭/故障时保留关键词检索。
- 已确认记忆仍以SQLite为准，语义结果按所有者、当前revision/有效状态/privacy_epoch再次检查，修改/遗忘/关闭后使旧检索失效。资料不自动成为记忆，任务仍需校对确认。

文档原件、业务库和对话检查点会随一致备份保留；恢复仍只允许空目录，不覆盖已有资料。向量索引是可重建派生数据，不进入备份。

## 实现与依赖
MarkItDown文档转换；pypdf逐页文本；Fetch同源ReadabiliPy/Markdownify正文流程，使用纯Python避免Node动态安装；FastEmbed/ONNX Runtime中文向量与QdrantClient本地索引。开源声明随App的Resources/OpenSource保留。无需用户安装Python/Node/Docker。

## 验证状态与边界
正式发布结果以本版manifest和验证记录为准。真实本地中文模型同义查询、资料语义命中与遗忘隔离已验证；公开示例网页实网读取已验证。合成资料、浏览器流程、冻结依赖与原生窗口分别记录，不代表所有真实课程文档/网站或任意同义表达都已验收。没有自动调用真实付费对话或视觉模型。

Zotero为下一版2.8的独立阶段，本版不声称已接入。当前包不含检索模型权重、密钥、个人资料/备份或开发环境依赖。
