# Demo2.6 · 可确认的个人记忆

本版接入已有个人档案、目标、执行摘要、周复盘和建议查询，并加入本地长期偏好记忆。版本号为2.6.0，发布目录为Demo2.6。截图闭环、独立App、原课表浏览器导入和桌宠保持可用。

## 使用方法

在助手中说“记住以后回答简短些”，助手先提出候选；等待本轮结束，在右侧点击“确认记忆”后才会生效。未确认、拒绝、过期或被手动设置替代的候选不参与记忆召回。新会话也可读取相关已确认偏好。记忆仅支持学习和交互偏好，任务、课程与截止时间仍走原有业务工具及确认流程。

设置 → 学习偏好 → 记忆与偏好，可以查看、添加、修改、设置有效期、遗忘和清空记忆；全局“待确认”的记忆页也可处理候选。永久专注/休息/每日学习上限直接同步已有个人档案，保留其他字段，不建立另一套偏好事实源。之后手动修改的档案值优先；遗忘时只清除仍匹配的关联值。

“使用已确认记忆”默认开启，“允许助手提出记忆建议”默认关闭。不允许建议时，只有明确要求记住或手动填写才能产生候选；任何候选都需本人确认。关闭召回不清除已同步的学习设置。

## 数据与遗忘

记忆保存在本机SQLite中，相关内容在使用助手时可能发送给已配置的模型供应商。每次最多召回5项、正文总计1000字，不新增向量库或外部记忆服务。程序拦截已知模型密钥、常见凭据格式、手机号、邮箱和身份证号码；这不代表能识别所有敏感表达，请勿主动提交敏感资料。

遗忘清除对应记忆及其候选内容；修改、遗忘、过期和关闭召回会切换后续模型上下文，避免旧检查点再次带入旧内容。既有聊天记录及已有备份保留，重新恢复旧备份可能恢复当时记忆。记忆事实变更需等待助手运行/批准结束；事实在批准前过期时不能继续批准旧请求，可拒绝后重提。清空个人资料同时清除新旧上下文检查点。

## 验证范围

本轮不自动调用真实付费模型。确定性测试不等于真实模型所有自然语言表达均能准确提取；真实截图准确率、学校最终保存、多物理屏、Windows/Intel等既有缺口仍保留。本版没有实现行为习惯学习、模型训练或自动调整计划，原总计划D留后续。Antigravity限定任务因登录超时未产出代码，本轮由主助手完成实现、审查与验证。
