当前2.6.1已正式发布，17项独立门禁全部通过。分支codex/chat-images-simple，批准参考docs/design/chat-images-simple/preview.html。

已通过：37项图片批次/旧单图/个人记忆后台测试，110项前端单元，9项图片/聊天端到端。覆盖图片追加/移除/校验、发送前不上传、取消勾选和日期选择、来源与证据、部分失败缓存/重试、取消、重启继续、截止留空保存、按编号只更新回答的条目、导航迟到回执和暂停动画帧下流式显示。解码迟到用例已发现并修复新会话创建期间清理时机，复核通过；另12项图片/作业后台检查通过，完整发布门禁继续。

UI不再为图片草稿打开右侧校对栏；任务列表、跳过日期与确认保存位于对话内。详情按需展开，原有课表、约束、审批和记忆入口保留。

Antigravity首轮后台返回print_timeout，只产生部分文件；前端任务stream interrupted。第二轮缩成两个附件组件文件后完成，主助手补API接线、任务卡、验证与边界修复。没有把CLI状态SUCCESS当作代码完成或测试成功。

全部使用合成数据和确定性模型，无付费模型调用；真实模型语言理解与视觉准确率仍待真实样本评测。

正式发布：741后端+20子项、110前端单元、98界面，以及原生逻辑/健康/集成、视觉参考、空资料复制首次启动和冻结后端检查通过。35项SHA256、签名、双ZIP CRC与三处配置根已知私密值排除复核通过；205个运行源码文件与打包时源码ZIP逐字节相符。发布包不可覆盖，原生/哈希收尾材料在本目录单独记录，不假称打包前已经存在。

CUA原生验收：正式App窗口/与发布包逐文件匹配的界面文件，连接显式隔离来源后端和确定性模型。系统NSOpenPanel实际同时选择两张图片，输入框显示两图；发送前资产数为0。发送后两项草稿、尚未写任务；点击暂不填写，再确认保存，两条任务均due_at=null，分别关联各自原图，原生任务页实际显示两条。冻结服务能力另由正式门禁验证，本轮没有调用真实视觉供应商。Finder跨窗口多图拖放和系统图片剪贴板本轮未人工重验；浏览器拖放/粘贴回归通过，旧单图人工验收记录保留，不混淆证据来源。
