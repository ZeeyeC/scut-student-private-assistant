已通过：37项图片批次/旧单图/个人记忆后台测试，110项前端单元，9项图片/聊天端到端。覆盖图片追加/移除/校验、发送前不上传、取消勾选和日期选择、来源与证据、部分失败缓存/重试、取消、重启继续、截止留空保存、按编号只更新回答的条目、导航迟到回执和暂停动画帧下流式显示。解码迟到用例已发现并修复新会话创建期间清理时机，复核通过；另12项图片/作业后台检查通过，完整发布门禁继续。

UI不再为图片草稿打开右侧校对栏；任务列表、跳过日期与确认保存位于对话内。详情按需展开，原有课表、约束、审批和记忆入口保留。

Antigravity首轮后台返回print_timeout，只产生部分文件；前端任务stream interrupted。第二轮缩成两个附件组件文件后完成，主助手补API接线、任务卡、验证与边界修复。没有把CLI状态SUCCESS当作代码完成或测试成功。

全部使用合成数据和确定性模型，无付费模型调用；真实模型语言理解与视觉准确率仍待真实样本评测。
