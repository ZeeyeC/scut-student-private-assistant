# 课表准确率离线评测

本工具只评估本地人工标注与校对前结构化原始预测，不读取图片/PDF、不连接数据库、不调用模型或网络。它不提供真实样本，也不会把合成回归结果算作真实准确率。

当前真实验收状态见 [ocr-acceptance-status.json](ocr-acceptance-status.json)。初始状态来自空样本评测：`status=not_evaluated`、`passed=false`，待提供真实材料；所有零分母准确率均为 `null`，不声称0%或100%。

## 使用

在源码根目录运行：

```bash
backend/.venv/bin/python scripts/evaluate-timetable-benchmark.py /path/to/private-manifest.json \
  --output /path/to/report.json --markdown /path/to/summary.md
```

`--markdown`可省略，`--help`显示标准帮助。输入只读；输入与输出（含符号链接解析后的路径）不得相同。不会复制原件、课程名、教师、教室等原文字段到报告；错误通过不含个人信息的sample/slot ID及字段定位，人工对照私有manifest复核。

退出码：`0`表示真实门槛达标；`2`表示已完成评测但未达标，包括空样本、只有合成样本；`1`表示格式、字段校验或文件读写错误。格式错误不生成新的结果报告。`--help`为0；命令行参数用法错误沿用argparse的2，需与报告中`passed=false`的正常评测结果区分。

[合成格式示例](timetable-benchmark-schema-example.json)仅演示输入结构。其`synthetic=true`，文件哈希来自明确的合成占位字符串，不是学校原件；不得更改标记后充作真实材料。

## 输入契约

顶层必须是JSON对象，且只含：

| 字段 | 约束 |
| --- | --- |
| schema_version | 整数`1`；不接受字符串、布尔值或其他版本 |
| samples | 样本数组；空数组可正常输出尚未验收的缺口 |

每个sample的必填字段：

| 字段 | 含义与约束 |
| --- | --- |
| sample_id | 匿名稳定ID；1～100个ASCII字符，字母/数字开头，其余仅字母、数字、`.`、`_`、`:`、`-`；不得使用学号、姓名或文件路径 |
| layout_id | 经人工分类的版式ID，约束同sample_id；不同文件不等于不同布局，不能任意改名凑5种 |
| input_kind | `image`、`text_pdf`、`scanned_pdf`三者之一；以原始输入类型分类，不以渲染后都是PNG混淆 |
| source_sha256 | 原始匿名输入文件字节的SHA256，64个十六进制字符；大小写归一后全局唯一 |
| anonymized | 严格布尔值；明确已匿名化才可为true |
| reviewed | 严格布尔值；人工核对标注、不可辨认项、预测对应slot及来源后才为true |
| synthetic | 严格布尔值；虚构、生成、拼接测试资料均为true |
| prediction_stage | 必填，`original`或`manually_corrected`。只有校对前原始预测可为original；校对后的正式课程/人工改过字段的预测必须为manually_corrected |
| expected | 人工标注的课程数组；每门必须含slot_id及4个关键字段，无法辨认的值写null |
| predicted | 校对前结构化原始预测数组；每门必须有人工核实的slot_id；未输出字段可省略或null，不能人工补成正确值 |

可选`date_range`必须同时含`starts_on`和`ends_on`，格式严格为`YYYY-MM-DD`，日期必须存在，结束不得早于开始。日期范围仅描述样本适用日期，不参与猜测周次或替代课程字段评分。

顶层、sample、日期范围和课程对象中的未知字段一律报格式错误，不静默忽略拼错的标记。重复sample_id、source_sha256（即使大小写不同）、同一侧重复slot_id均拒绝整个manifest；同一份文件不能通过多个ID、布局名或输入类型重复凑样本。该工具不读取原件，真实哈希、匿名化和人工复核声明仍须由资料提供者审计；无法自动识别换格式、重新压缩后的同源图片，人工还应排除这类近重复。

## 配对与字段归一化

`slot_id`表示原始来源中的稳定课程行/单元格，例如`p1-r3-c2`。人工只确认“该预测对应哪个来源格子”，不得为匹配而修改其课程字段。预测数组不按顺序或课程名自动配对；名称相同但slot不同仍记为漏识和多识。确实多出的预测用新的匿名ID（如`extra-001`）保留为多识，不能删除后再测。

| 课程字段 | 归一化和合法范围 |
| --- | --- |
| name（必测） | 非空字符串或null；NFKC，再去首尾空白、把连续Unicode空白压为一个普通空格；保留内部词边界，区分大小写，不删标点、不做近似/别名匹配 |
| weekday（必测） | 严格整数1～7或null；不将`"1"`、`true`、0自动转成星期一 |
| weeks（必测） | 整数数组，每项1～30；排序去重。人工标注非null时必须非空；预测空数组按缺失内容计错；不将字符串周次或浮点数宽松转换 |
| periods（必测） | 同weeks，节次范围1～30；非连续节次原样保留为数值集合，不补齐中间节次 |
| teacher/location/campus（可选） | 标注时可提供字符串或null，归一化同name；缺少该标注或值为null时不入分母 |

周次/节次数组去重前最多30项，1～30范围与当前课程契约一致；不从日期范围猜学期或补课。若模型原始协议需要确定性的结构转换，应固定并审查该适配规则、保留私有原始预测；不能使用校对答案替换错误字段。此工具不实施模型调用或任意自然语言解析。

## 分母、错误和验收门槛

每个已知人工标注字段贡献1个分母，配对字段归一化后完全相等才算正确。标注为null代表不可辨认/未标注，不因预测有值就加入分母；null也不等于0。漏识课程保留其所有已知字段分母并分别记错。额外课程对name、weekday、weeks、periods各增加1个错误及1个分母，即使额外预测漏掉该字段；额外课程提供的非null可选字段同样计错。因此这里的字段准确率是明确包含多识惩罚的`正确 /（已知标注字段数 + 对应额外预测惩罚数）`。

报告逐字段提供`denominator/correct/incorrect/accuracy`，准确率为0～1比例，分母为0时为null。每组同时给出课程expected/matched/missing/extra、样本数、布局ID/数量、三种输入的样本数；`errors`逐项列出sample_id、slot_id、field和reason，不回显原文字段。课程缺失/额外事件与字段错误分别记录，汇总准确率只使用字段计数，不把事件再次重复相加。

三组完全分开：

- `groups.real`：真实、已匿名、人工复核、原始预测、至少一门有可评分关键字段的课程；唯一用于验收门槛。
- `groups.synthetic`：所有合成样本的诊断结果；无论多高均不能填真实样本或布局数量。
- `groups.excluded_real`：非合成但未匿名、未复核、预测已人工改正、没有标注课程或全部关键字段不可辨认；只供诊断，不入真实门槛。具体原因在`excluded_samples`。

仅当以下条件同时满足才`passed=true`：

1. 至少30份满足上述资格的真实匿名人工标注样本，全局source_sha256无重复。
2. 至少5种真实样本布局，且image、text_pdf、scanned_pdf三种输入都有真实合格样本。
3. name、weekday、weeks、periods各自分母非0，且各自准确率≥95%。使用整数交叉乘法检查未四舍五入的比率，可选字段单独报告但不降低这些门槛。

`gaps`逐项返回不足的样本、布局、输入类型和字段准确率；未满足不能写成验收通过。`status=not_evaluated`表示没有合格真实样本，`evaluated`表示至少有一份合格真实样本，仍须看passed。`pending_real_material`表示真实样本数量/布局/类型覆盖仍缺材料；已有足够材料但字段准确率不达标时可为false，而passed仍为false。

本工具测试内会用明确合成的临时fixture、临时切换元数据检查30份及95%门槛分支；这些是算法回归，测试后不保存为真实数据，不进入当前真实验收报告。新版打包、单元测试通过和合成例子100%均不能替代T01真实验收。
