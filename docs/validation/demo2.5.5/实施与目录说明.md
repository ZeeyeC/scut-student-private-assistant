# 实施与本地目录整理

根因：CmdQ绑定仅退出桌宠；正式App启动使用显式资料根，双击则回默认目录导致数据库身份不同，旧后台占用5173。

修复由Antigravity ArgonMedium生成，主助手检查四原生文件。正常终止使用terminateLater、认证停止接口及成功/失败回复；高级仅退出显式旁路。成功正常启动且--remember-data-dir时记住目录和模式，隔离验收不持久化。主助手去除依赖源码文件存在来猜测projectMode，保持原显式路径语义。

资料仍在原工作树，不搬动数据库/私密配置。源码历史已在GitHub，但本地App历史包未作为发布资产上传，因此本轮集中归档而非删除。目录整理记录含精确移动前后位置。其他非本项目文件不操作。

代价：记住的路径必须继续存在；原源码目录仍不能随意移动。高级仅退出会保留后台，普通退出才能完整停止。后台忙或拒绝停止时保留App，用户应先完成当前操作再退出，不强杀。
