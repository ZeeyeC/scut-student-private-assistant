# 2.6.0 个人记忆验收

当前阶段：2.6.0已正式发布，17项独立门禁全部通过。分支codex/personal-agent-memory，2.5.7用户已确认原生拖放/粘贴预览通过。

33项相关后端测试通过，覆盖真实DeepAgent图、确认候选、跨会话召回、同会话遗忘隔离、重启检查点恢复、过期阻止旧批准、清空检查点、个人业务工具、所有者隔离和敏感内容排除。3项记忆端到端用例通过：提出/确认/新会话/遗忘、数值档案/修改拒绝/关闭/清空、错误保留/安全文本显示。前端构建与新增Python静态检查通过。

界面验收修复了助手未结束时的提前确认、受控开关等待回执的回跳、textarea内容改变后的标签查找问题。Antigravity两次限定任务均登录超时未生成源码，主助手接手实现，未使用其他模型冒充指定CLI。

所有数据和模型均为隔离合成夹具，无付费模型调用，无个人数据库测试写入。真实模型的自由表达提取、真实视觉准确率、学校最终保存、多物理屏、Windows/Intel仍非本次完成项。行为习惯学习与自动调整计划留后续。

完整结果：733后端+20子项、109前端、95界面、浏览器本机会话、原生逻辑/健康/集成、冻结服务、视觉参考、空资料复制首次启动通过。35项SHA256、App签名、源码ZIP和应用ZIP的CRC、三配置根已知私密值排除均复核通过，见release-verification.json。

正式App与冻结后台另做显式隔离资料验收：候选不提前生效，确认后专注25分钟同步档案，重启保留；CUA在原生设置中确认另一候选，界面计数1→2，API独立核对真实事务。测试直接子进程曾随父进程退出而遗留隔离后台，默认目录连接被身份校验阻止；仅停止该隔离服务后改用LaunchServices重开，同一资料恢复并完成验收。该测试启动过程不冒充产品无故失败，个人资料未作测试写入。

正式新版最后无参数打开，原资料身份、模型配置状态核对通过。14份本次自动化生成的历史路径材料已复制到本版regenerated-evidence，再恢复历史已提交原件。发布包不可覆盖；源码ZIP是打包当时工作树，随后补充的本文件和原生/哈希收尾记录单独本地提交。真实付费模型与原始总计划拓展项未因此视作完成。
