# V2 浏览器审片版

用户意见：动画不够有冲击力，节奏慢，反复采用“上字下画面”。本轮直接调整已有视频，保留真实功能结果和全部虚构业务素材。

## 当前入口

- 原入口 `http://localhost:3010/StylePreview` 已改为 V2 全片。
- `http://localhost:3010/CampusPromoV2`：同一版 62 秒主片，1920×1080，30fps。
- `http://localhost:3010/HomeworkPreview`：15 秒 V2 作业整理样段。
- V1 在 Studio 的 `Earlier` 文件夹保留作对照。

用户明确不需要导出，本轮不生成最终 MP4，不增加旁白或音乐，不调用模型，也不再操作 App 或个人资料。

## 实际修改

| 内容 | V1 | V2 |
| --- | --- | --- |
| 主片长度 | 75秒 | 62秒 |
| 构图 | 标题在上，统一窗口框在下 | 左右交替分屏、全幅界面、错位卡片、数字主视觉、桌宠与文字分区 |
| 开场 | 信息卡缓慢淡入 | 深色大字依次揭示，原图卡旋转进入，强调条横向进入 |
| 截图作业 | 输入、结果采用相同框 | 原图与大字分屏 → 草稿全幅近景 → 日期错位构图 → 待办侧向展示 |
| 学习安排 | 同一窗口框重复出现 | 深色节奏卡 → 课程窗口侧推 → 时间数字与草稿分屏 → 今日结果全幅展示 |
| 课程资料 | 标题加列表 | 文件与讲义叠层，答案数字与真实来源并列 |
| 长期记忆 | 同一框展示7秒 | 25分钟数字卡、确认卡片大近景、新会话召回反向构图 |
| 桌宠 | 标题在上或左 | 标题与奶蛙/待办区域分开，缓慢推进，保留完整任务卡 |
| 转场 | 主要硬切 | 8帧短擦除/推移；18个镜头、17处转场 |

颜色以深蓝紫、原产品浅灰蓝和紫色强调交替。动效由 Remotion 帧驱动，不使用 CSS 动画；转场使用官方 `@remotion/transitions` 4.0.540。关键结果留2–5秒，短节奏卡与信息量较大的结果镜头交替。

## 时间线

1. 00–06秒：大字开场、品牌与完整窗口。
2. 06–18秒：作业原图、两项草稿、日期补充、保存结果。
3. 18–31秒：课程、安排草稿与正式今日安排。
4. 31–38秒：课程资料与真实问答来源。
5. 38–49秒：偏好数字、人工确认与新会话召回。
6. 49–57秒：桌宠待办与卡片蒙太奇。
7. 57–62秒：品牌片尾，最终文案稳定停留。

所有18段的主体时长合计1860帧。前17段各增加8帧，17个转场各重叠8帧，最终仍为1860帧；15秒样段按相同方式计算，最终450帧。精确时序记录在视频工程 `work/v2-timeline.json`。

## 验证边界

先前原始录屏中的剪辑缺口仍然存在，本次改变包装和节奏，没有伪造新响应。未重新调用模型，授权8次请求仍保持8次。当前为无声审片版，完整播放的感受和节奏仍由用户审阅。

本轮文字入场曾因百分比/像素混用报错，已在动画起止值统一单位。当前浏览器自动控制在 Work 设置中关闭，不更改该设置；通过官方 Remotion 渲染器检查本地场景与转场静帧，浏览器原入口仍可由用户直接查看。
