# V2 音频制作

用户认可V2并要求制作音频；继续沿用62秒画面，在浏览器试听，不导出视频。

## 制作选择

采用已批准方案中的中文旁白、轻电子背景音乐、少量转场音效。具体音色由本轮制作选择：清晰女声，语速略快，句间保留画面阅读时间；不逐字复述屏幕上的所有文字。

- 旁白：优先使用 `rany2/edge-tts` 调用 Microsoft Edge 在线语音服务的 `zh-CN-XiaoxiaoNeural`。只发送本轮宣传文案，不发送用户数据、不复用 App API Key、不增加此前8次业务模型预算。不使用付费配音服务。
- 背景：用本地Python/NumPy原创合成120 BPM轻电子乐，不下载第三方歌曲。持续音、分解音、低音和节拍逐步进入；旁白时自动降低伴奏。
- 音效：本地合成短促滑动和落点音，在主要转场、确认结果处点缀；保持低音量。
- 备选：若免费在线TTS无法连接，先保留音乐/音效与旁白时间表，并尝试系统已安装语音作为明确标识的小样；不自行启用付费服务。

## 时间与验证

逐段生成并测量旁白，按实际长度放入画面时间槽。超长时先缩减文案，再微调语速；不截断语句。各段留至少0.12秒余量。全片62秒，样段15秒分别混音，均淡入淡出。

将旁白、音乐和音效作为独立音轨接入Remotion；生成本地试听混音用于检查峰值、响度与节拍，不输出视频。确认无削波、时长正确、各句未越界后提供浏览器试听。完整主观听感仍需用户试听确认。

## 原始时间段

00–06秒：课表、作业、资料，接进同一个流程。

06–18秒：截图变待办，核对要求、补充或保留日期、确认保存。

18–31秒：结合已有课程生成安排草稿，确认后进入日程。

31–38秒：资料按课程收好，回答标明来源。

38–49秒：25分钟偏好，确认后记忆，新会话继续召回。

49–57秒：关掉窗口，桌宠仍可查看今日待办。

57–62秒：课间，让学习安排更清楚。

免费TTS属于第三方在线服务，当前生成物用于审片；开源客户端代码许可与在线服务输出使用范围分别记录，不把客户端许可写成配音输出的无条件商用授权。

## 本轮结果

18句中文旁白已生成；修剪句首句尾静音后均完整落入时间槽，主版没有额外变速。原创120 BPM配乐和合成音效分别制作62秒与15秒版本，按旁白时间槽降低伴奏，首尾淡化。`PromoAudio.tsx`将三条独立音轨接入原`StylePreview`、`CampusPromoV2`与`HomeworkPreview`入口。

ESLint + TypeScript通过；实际从两套Remotion composition生成内部音频检查文件后，验证分别为62.000秒与15.000秒，独立音轨求和与实际输出相关性均大于0.99999。主版约-18.03 LUFS / -2.92 dBTP，样段约-16.75 LUFS / -3.35 dBTP；无削波，语句不重叠、不越界。详见视频工程`work/audio-validation.json`。

本轮没有导出视频，没有付费服务调用，也没有增加业务模型请求。当前浏览器控制在Work设置中关闭，未改动该设置；最终听感由用户在浏览器试听确认。
