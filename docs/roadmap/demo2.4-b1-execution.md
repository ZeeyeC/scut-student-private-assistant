# 乙方 B0/B1：实际执行补记与更正

状态：乙方功能分支交付，待甲方契约复核与合入；不是新正式发布。基线为Demo2.4 `36c9bef93cd8fb961a955842f7d2b2db4dee44cc`，分支`codex/after-demo2.4-execution`。

## 使用

在“今日”的学习安排或“查看 / 拆解步骤”中打开“实际执行与反馈”，填写实际分钟和日期，选择本次结果、可选原因，以及是否改变整项任务状态，再保存。步骤详情可选择对应的学习安排；不指定单次时，必须明确本次是否覆盖当前全部安排或属于另一段投入。计划时长保留；未填写不自动记为0。完成一段执行不自动完成整项任务。

已有反馈可在“执行与更正历史”选择更正；新值生效，原值保留。网络结果不明时使用“重试保存执行反馈”，沿用同次操作，避免重复累计。同一步骤的多个时间块分别展示各自观察值。

旧时间块完成入口明确标为“按计划时长记录估算”，不会冒充真实投入；桌宠右击仍只完成任务。旧估算覆盖范围不明时，用户选择“替代旧估算”或“另一段投入”，程序不静默相加。

## 数据与兼容

沿用Resource、Receipt、SQLite事务、全局资料版本和planning_event；新增execution与execution_baseline资源，不修改物理表结构，不新增数据库或Key入口。无用户操作时，旧资料只读投影，不在启动/读取时回写。

事实、更正、投影、事件和幂等回执同事务保存；执行变化使旧计划不能继续确认。任务删除级联其执行/基线；已有执行事实的未完成步骤暂拒绝重新拆解，保留事实关联。完整导出、停服备份和恢复沿用原机制。
