# 资料、网页、语义记忆与Zotero实施计划

基于2.6.1，分支codex/knowledge-web-semantic。用户确认先完成推荐表1/2/3并打包，再完成4。对应：文档资料读取、网页读取/可配置搜索、语义记忆；随后Zotero文献助手。首版2.7.0，后续2.8.0；不加入语音、通用浏览器自动化或行为自动学习。

## 第一阶段：2.7.0
- [x] K1 MarkItDown文档入口：PDF/Word/PPT/Excel/纯文本；选择、拖入/添加，与图片入口兼容；发送前仅本地选择，发送后解析；资料列表可查看、删除、按课程关联。保留来源文件名、真实页码或段落/章节定位；扫描件无文本诚实提示。
- [x] K2 资料问答：所有者隔离、分段和有界检索、对话工具带来源；资料指令视为不可信；提任务复用已有草稿和确认，不自动保存。跨会话资料保留；删除后旧检查点失效。
- [x] W1 公共网页读取：用户给链接读取文本、标题和来源；校验协议/IP/DNS/重定向，限时限量；不唤出浏览器，不读取学校登录/私网。使用官方Fetch的内容提取组件及受限网络适配器。
- [x] W2 配置SearXNG搜索：App内开关/连接检测/可配置地址；无服务时明确未配置，链接读取独立可用。不内置公共实例或暗中上传个人资料。
- [x] M1 Qdrant本地索引+FastEmbed中文模型：显式准备模型，展示真实状态；正式记忆仍由SQLite确认、过期、遗忘管理，检索结果校验用户、版本和状态；向量索引可重建，不保存记忆正文。缺模型明确回退关键词，真实模型本地语义测试独立记录。
- [x] M2 聊天召回接入、遗忘/关闭/清空及旧检查点保护；资料与偏好隔离；重启和损坏恢复验证。
- [x] V1 自动化：文件类型/大小/OOXML炸弹、所有者隔离、幂等、网页SSRF/重定向、无搜索配置、语义失效/遗忘、聊天来源及原图片流程回归。
- [x] V2 原生与冻结验收、完整门禁；更新VERSION/README/技术栈/许可说明，独立构建2.7.0 App+双ZIP+说明+manifest+SHA，成功后清理已知生成物。

## 第二阶段：2.8.0（2.7.0发布后开始）

## 开发和验收原则
按用户偏好由Antigravity CLI gemini-4-argon-medium/medium实现主要代码，在脱敏源码副本中工作；主助手集成、审查、测试、原生验收和打包。保持已认可界面，入口放现有聊天附件及设置，不新增繁杂主导航。第三方解析库可直接Python调用，不为协议额外启动无必要进程；MCP接入复用langchain-mcp-adapters并固定工具边界。默认SDK1.x，所有依赖兼容性由锁文件与冻结门禁验证。

不操作真实课表/个人数据库，不自动付费模型测试，不公开上传安装包。源码和进度持续本地提交；代码推送沿用用户已授权的项目分支范围，main不自动合并。已发布2.6.1保留直到新发布检查成功。实现、合成测试、实际冻结程序、真实外部样本分别记录。
