# 聊天流式输出与自然语言任务

用户请求：助手回复逐步出现；可通过自然语言新增任务。沿用已有本地模式、Deep Agents、assistant-ui、数据库草稿和真人确认，不增加新运行环境。

## 验收与实施

1. 后端使用锁定 LangGraph 的 messages/updates 双流；仅公开主聊天模型文本，不输出 reasoning、工具参数或嵌套工具模型内容。首片段立即落库，后续适度合并；最终文本和片段共享消息标识。
2. 前端按事件游标归并文本，最终消息替换部分消息。SSE 异常断开自动带游标重连，刷新重放不重复，运行结束恢复发送状态。
3. 提示模型遇到“新增任务/待办/作业”调用 create_assignment_draft。可省略要求；保留截止原文，未明确钟点的截止时间为空。展示可编辑任务草稿，经用户确认后才创建任务。
4. 有意义的回归：延迟模型第一片段在运行结束前入库；重放/重启、隐藏推理、最终消息一致；自然语言草稿尚未写任务，重复确认只保存一次；前端断线重连与消息去重；窄屏 GUI 生成途中刷新与校对后保存。
5. 完整后端检查、前端构建、隔离真实模型探针；重构建桌面包并恢复本地服务。测试模型/合成数据与真实模型证据分别记录。

## 官方接口依据

- https://docs.langchain.com/oss/python/langgraph/streaming
- https://www.assistant-ui.com/docs/runtimes/custom/external-store

使用现有锁定依赖，不改 SDK 版本；采用已检查源码和回归探针支持的 v1 多流 tuple 格式。
