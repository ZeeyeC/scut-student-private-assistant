记忆默认本地保存，相关内容在用户使用模型时可能发送给已配置供应商。遗忘清除记忆存储及候选版本，后续模型使用新上下文；既有聊天记录与备份保留，界面说明范围。记忆变更需等待运行/审批结束，避免正在处理的请求重新引用旧内容。
