# 日程、待办可见性与七天计划

目标：修复助手无关导入说明、自然语言活动误归任务、课表仅有课程、待办入口不明显、无步骤时计划空白。

验收顺序：
1. 首先回归无步骤任务必须出现在未安排原因；重复生成仅一个有效计划草稿，无内容不能误导保存。
2. 复用 fixed_event 与草稿确认事务，新增 calendar_event 草稿和受限工具 create_calendar_event_draft/list_calendar_events。校验带时区且有序，真人确认前无日程，重复确认不重复写，权限/旧版本失败。
3. 统一日程读取课程、固定事项、学习安排；课程配置错误不遮蔽固定事项。课程/事项/学习时间块不同颜色，展示范围与时区一致。
4. 复用现有流式 ChatPage 在课表页对话；全局仅一个 BrowserImport 桥接器，平时助手不显示无关学校引导。聊天返回草稿，确认后日历刷新。
5. 今日/课表列出已保存待办与未保存草稿，提供显式入口。待办无步骤时可填写实际预计分钟，使用现有步骤草稿+确认，不擅自猜耗时；七天计划显示未安排原因、空态、下一步，旧计划只显示最新一项。
6. 隔离自动化验证、真实供应商自然语言日程探针、重新构建 macOS 包、自检、恢复用户服务。生产数据不自动迁移/确认/删除。

复用 FullCalendar 标准版、assistant-ui、LangGraph 工具/持久检查点、SQLAlchemy JSON resources 与现有事务，不增加基础设施或依赖。
