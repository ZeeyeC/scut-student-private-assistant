# 简化多图对话与作业整理（2.6.1）

分支codex/chat-images-simple，基于2.6.0。用户确认技术方案并同意使用对话区预览，参考docs/design/chat-images-simple/preview.html。只实现当前批准范围，不改主导航、记忆或排程规则。

- [x] S1 多图输入：拖入/粘贴/选择连续追加，从输入框左上逐张排列、换行、单图移除；发送前仅本地预览。取消授权勾选和日期选择，保留发送用途轻提示，发送动作才提交consent=true。
- [x] S2 持久批次：最多5张/次、单张沿原10MiB/2000万像素限制；稳定批次与逐图上传键、同用户/会话归属、历史回放、取消、失败重试；保留成功识别缓存，不重复创建草稿。保留旧单图API与已有记录兼容。
- [x] S3 应用内作业整理Skill：识别后列出每项任务；只问缺失截止日期，一次按编号询问，可跳过、不回答保持due_at=null，不猜钟点。截图相对日期无原消息时间不默认上传日；后续用户新回复才用该消息日期计算。原草稿原地补充，保存仍需明确确认。
- [x] S4 对话内简洁任务列表和确认保存；原图/来源及完整校对详情可展开，图片草稿不再挤入右侧。课表、约束和记忆原有入口保留。
- [x] S5 隔离合成后端/前端/多图端到端、导航迟到回执、重启、部分失败缓存/取消、日期留空及无记忆污染回归；新旧API兼容检查。
- [ ] S6 更新VERSION、README和本版说明，从源码独立构建2.6.1，17门禁及原生验收，签名/双ZIP/SHA/私密值扫描，恢复原资料、整理并本地提交。不自动上传或付费模型测试。

按用户要求优先交由Antigravity gemini-4-argon-medium/medium实施，主助手集成审查、验收与打包。代码实现、合成测试、原生操作与真实模型效果分开记录，不以预览宣称完成。
