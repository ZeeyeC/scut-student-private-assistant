# 助手 Markdown 与数学公式显示

用户已确认复用开源组件并要求实施，授权来源为本轮“帮我实现吧”。

只替换助手回答的纯文本显示，支持标题、强调、列表、引用、链接、GFM表格/任务列表、围栏代码及KaTeX行内/独立公式。用户消息与附件、草稿审批交互保留。原始消息继续原样保存，历史与流式消息走同一渲染器。

## 方案

复用@assistant-ui/react-markdown，与已有assistant-ui运行时直接配合；remark-gfm补充表格，remark-math/rehype-katex和KaTeX处理公式。手写解析器易遗漏语法与流式边界；直接react-markdown需要额外适配上下文，故选择前者。

## 约束与验收

保留smooth=false，收到的消息不能依赖requestAnimationFrame才显示；原始HTML不执行，链接限定HTTP/HTTPS及页内锚点，远程图片不自动加载，公式trust=false。Markdown任务勾选仅展示，不连接业务任务。

局部CSS与现有蓝灰风格一致，正文保持正常留白，标题克制。列表缩进、换行、长链接、表格/代码/公式溢出均不得撑宽聊天或遮住输入框；代码与表格可横向滚动。代码可复制，附件流程照旧。

公式支持标准$...$及$$...$$；同时兼容模型常见的\(...\)和\[...\]，但不得改写代码块/行内代码。公式不合法时保留可读内容，不令整条回答崩溃。不新增自动外部访问。

默认不加入Mermaid、富文本编辑器或远程图片预览；本轮不改变模型提示词、后端和资料存储。使用已安装版本兼容的固定依赖，第三方许可随App打包。发布2.9.2，遵循独立完整验收流程，不调用付费业务模型。
