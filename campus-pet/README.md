# 课间 · Mac桌宠与独立助手

当前开发分支为 `codex/demo2.5-app-ui-naiwa`。本地2.5.0已归档于工作区`Demo2.5/`；构建及验收结果见[进度表](../docs/roadmap/Demo2.5-开发进度追踪表.md)，已有Demo2.4.9及其他归档保留。

日常操作在独立App中完成，使用Swift/AppKit窗口和内部WebKit工作台。外部浏览器只用于学校课表登录与导入：默认指定Chrome，可在设置选择Edge并记住选择；不使用系统默认Safari。

## 使用

- 主窗口与快捷面板共用今日、日程、任务、助手四项导航。设置位于侧栏底部；窄窗口使用底部导航。
- 今日显示下一项任务和日程摘要；“执行与记录”包含排程、执行反馈及自愿计时，“课后作业”打开原作业询问。
- 日程通过全部、课程、学习筛选同一份数据。安排学习、课程规则、固定事项、课表导入和事件详情按需打开。
- 任务保留待办、目标与复盘。点击任务行查看要求、步骤、执行反馈和类型；新建任务先核对再确认保存。
- 助手使用原对话、草稿及审批流程；待确认集中展示草稿、建议和时长建议。保存前仍需明确确认。
- 设置分为课程与学期、学习偏好、提醒与桌宠、模型连接、资料与备份。资料与备份中的“关于课间”显示本机素材声明和可复制来源，不打开浏览器。

## 桌宠

单击角色展开今天已安排的未完成任务环，最多6项，超出的保留并在完成后补位。同一任务多个学习时段合并；仅截止却未安排、未来任务以及已完成任务不进入任务环。左击气泡查看详情，右击完成任务，不伪造实际学习投入。再次点击、拖动、隐藏或点击外部时收起。

拖动角色可移动位置；透明像素允许点击下方窗口。原图按420×560等比显示，绘制与透明点击共用坐标变换。提醒使用原角色配合轻量紫色状态提示；仅角色肚皮区域触发预设快捷目标。网站链接在App内显示并复制，本机文件仍由文件默认应用打开。

动作来自固定来源素材清单：打招呼、微笑为单帧800ms姿态，惊讶按入场/主体/退场原时序播放。7种业务状态使用对应角色片段；审批、提醒与忙碌会打断表演。隐藏、休息及系统“减少动态效果”停止不必要的推进，随机表演仅在空闲时发生。

帧按需校验与解码，使用64MiB LRU缓存；坏帧回退到同一新角色的默认帧。实际新包中不包含旧视频动作或旧角色回退。旧源码和历史归档仍保留。

## 导入学校课表

在日程点击导入课表→学校课表。App提供扩展安装指引与浏览器选择；只有点击开始导入才会唤出所选Chrome/Edge。浏览器只接收本次导入的短期授权，回传后回App核对，课程不会自动写入。

本版扩展为0.1.2；旧扩展需要从App提供的目录更新/重新加载后使用。取消、过期和失败会清理对应代次的采集绑定，旧桥接不能误停新的重试。

未安装浏览器/扩展、登录中、取消、过期与回传失败均在当前导入流程内处理。真实学校登录和实际字段准确率仍需本人实测；合成学校测试不计入真实样本数量。

图片/PDF、文字和手工录入保留在导入抽屉；日历周视图的空白格也可添加课程。学期、周次或节次未知时保持未知，不猜学校作息。

## 构建与验证

素材的固定提交、原路径、SHA256、GPL/NOTICE及用户提供的许可依据见[来源记录](art/naiwa/SOURCES.md)和[选择清单](art/naiwa/selected-assets.json)。没有使用上游运行程序。

```sh
backend/.venv/bin/python scripts/import-naiwa-assets.py --source <固定提交的干净检出> --selection campus-pet/art/naiwa/selected-assets.json --output campus-pet/Resources/NaiWa
backend/.venv/bin/python campus-pet/build.py
backend/.venv/bin/python scripts/verify-pet-asset-pack.py --release --app campus-pet/dist/课间桌宠.app
backend/.venv/bin/python campus-pet/verify.py
```

开发可用 `tests/make_asset_fixture.py` 生成明确标记的合成QA图形，并通过 `build.py --pet-assets <目录>` 进行测试；正式发布检查拒绝这种QA包。发布按[发布流程](../docs/releases/发布流程.md)独立构建，不复制旧App、不覆盖旧版；打包附当前源码与声明，不包含Key或个人资料。

关闭助手窗口保留桌宠；菜单“仅退出桌宠”保留后台，“停止后台并退出”需确认。重新打开会复用本机资料和模型配置。源码目录保持原名，避免破坏旧App与个人数据路径。
