# 课间奶蛙 · Mac 助手桌宠

当前版本 Demo2.4（App 版本 2.4.0），新增单次调课、停课和恢复原课；包含当日排程，入口与限制见 [Demo2.4 说明](../docs/releases/Demo2.4.md)。历史录屏保留在 [Demo2.2 说明](../docs/demo2.2/README.md)。

这是独立的新项目目录，复用仓库内现有的 FastAPI、React、Deep Agents 和数据校对流程。桌宠和独立助手窗口用 Swift/AppKit/WebKit 实现。

## 打开

双击工作区 `Demo2.4/课间桌宠.app`，或者双击 `启动课间桌宠.command`。启动脚本优先使用 VERSION 对应的发布包；尚未发布时才构建 `dist/课间桌宠.app`。每版验证打包后会清理旧 `dist`，以免误开旧 App。

- 单击奶娃或它上方的状态提示，在身旁环形展开**今天已安排的未完成待办**。每项待办一个圆形气泡，中央显示一到两个字的缩写；左击查看详情，右击直接完成整个待办。
- 再次点击奶娃、点击气泡外、拖动或隐藏奶娃时收起气泡；展开待办气泡不会唤出助手窗口。气泡自动选择屏幕内的圆环或弧线位置。
- 拖动角色移动位置，松手后记住位置；透明区域允许点击到下面的窗口。
- 右键桌宠，或点击菜单栏的星光图标，可打开今日、设置、暂停动画、隐藏、恢复和退出。
- 面板顶部切换助手、今日、课表、待办、设置。“展开”切换为完整工作台。
- 助手处理、流式回复、等待校对时，角色显示对应气泡与轻微动画。
- 右键 → **表演动作**，可以播放视频里提取的**闪身步、大抡臂、狗熊哆嗦毛**。三个动作均为去背景、无声音的逐帧动画，播放完回到待机。选择“停止当前动作”可立即结束。
- “狗熊哆嗦毛”原速连续播放两遍，总时长 **6.6 秒**；另外两个动作播放一遍。
- **自由表演**默认开启：空闲时约每 18～32 秒随机做一个动作；可在右键或菜单栏取消勾选，设置会记住。助手忙碌、休息、隐藏或系统开启“减少动态效果”时，不会随机表演。
- 暂停会停在当前动作帧，恢复后继续；暂停期间仍会记录助手的最新状态。隐藏时不推进动画。动作保留在悬浮窗内，暂未加入在桌面上自由行走。
- 待校对时，点击奶娃仍只展开今日待办气泡；可从右键“和我聊聊”打开助手，再点击“查看待校对”定位草稿和审批区域。
- 切换到设置、待办或课表后，桌宠仍会同步后台任务及待确认状态；点击助手中的待确认提示会定位相应会话。
- 关闭面板后桌宠继续显示。右键桌宠或点击菜单栏图标，在 **关闭与退出** 二级菜单中选择关闭方式；桌宠外观不增加常驻关闭按钮。

## 今日待办环

只显示已保存到当天日程的未完成学习任务，按设置中的时区判断日期，并按当天最早的学习时段排序。仅今天截止但未安排、逾期但未安排、未来才安排的任务不会显示；已完成或归档的任务、已完成的学习时段不会显示。跨午夜的未完成时段在覆盖的当天显示。同一任务多个时段合成一个气泡。

最多同时显示 6 个，超出的先隐藏。右击气泡会保存整个任务为“已完成”，成功后在原位置补入下一项，其他气泡保持位置；任务详情和待办管理使用同一份记录。此操作沿用原任务完成方式，不虚构学习投入。误操作可在“待办与日程”展开该任务的步骤，点击“重新打开作业”恢复。

悬停查看完整标题；左击打开独立详情窗口，可查看要求、今天的安排、截止时间、提交方式和步骤。没有当天安排时显示“今天没有待办安排”。展开期间约每 15 秒刷新；保存失败或版本冲突不会擅自移除任务，刷新后可重试。课表和待办管理可从右键或菜单栏打开助手后切换；完整浏览器界面可从右键菜单直接打开。

## 关闭与退出

- **仅退出桌宠（后台继续运行）**：退出桌宠和助手窗口，浏览器继续使用同一后台。`Command-Q` 对应此行为。
- **停止后台并退出…**：确认后安全停止共享后台，再退出桌宠；确认框会说明 Web UI 也会断开，请先保存编辑中的内容。取消不会停止服务。
- 后台正在处理请求、由终端管理或连接异常时会显示原因，保留桌宠供重试；也可以选择仅退出桌宠。停止超时不会被当作成功。
- `Command-W` 继续只关闭助手面板。后台停止后，再次打开桌宠会按原方式启动服务；个人资料和模型配置会保留。

桌宠与 Web UI 可以同时使用新版后台。如果启动时提示旧版后台，请在旧助手的设置中停止服务，再使用桌宠菜单“重新连接本机服务”。无需删除项目、数据库或模型配置。

聊天、查课表、创建任务、生成日程和计划复用原应用；正式保存仍需校对确认。模型未配置时，在设置填写模型连接，桌宠本身不需要模型调用。

课表导入需要 Chrome/Edge 扩展，原生 WebKit 不运行该扩展。点击面板上方“课表导入请在浏览器打开”，并按原项目导入向导操作；默认浏览器不支持扩展时，请自行在 Chrome/Edge 打开 `http://127.0.0.1:5173`。

## 点击课表添加课程

在“课表”切换到“周”视图，点击空白时间格即可弹出课程表单。自动带入星期、所选日期的教学周及匹配的实际节次；默认只添加到所选周，可自行修改周次、节次和地点。生成草稿后核对并确认保存，课程随即出现在课表中，并参与课后作业询问。取消填写不会创建草稿。

原“手工添加课程”入口继续保留。没有配置学期日期、实际节次时间，或所选格子没有对应节次时，会提示手动补齐；不会猜测学校的作息。窄窗口默认显示列表，点击“周”即可使用空白格添加。

## 日程提醒与肚皮快捷打开

桌宠运行时，课程、固定事项和学习安排会在开始前约 5 分钟触发无声提醒（每 15 秒检查一次）。奶娃的黄色身体变成紫色，浅色肚皮保留；提醒期间停止随机表演。点击肚皮打开这项日程预设的网站或本机文件；点击其他部位展开今日待办环。没有设置快捷目标时，点击肚皮打开待办与日程。

在“待办与日程”点击一条日程，在“提醒与快捷打开”选择网站或本机文件并保存。桌宠 App 内可直接“选择本机文件”；浏览器里可粘贴完整文件路径。课程设置针对所选这一次课程，不影响其他周次。可单独关闭某项日程的提醒。

同一次日程只首次提示，关闭再打开 App 不重复提示；多个提醒按开始时间依次处理，点击打开当前项后显示下一项。开始时间到达后自动恢复黄色。App 未运行或电脑休眠时不发出提醒，已经开始的日程不补提醒。网页链接在默认浏览器打开，文件通过系统默认应用打开；文件已移动、删除或无法打开时显示原因并保留提醒以便修改。打开前会再次核对日程是否仍有效。

## 课后作业询问

默认在一天最后一节课结束满 **30 分钟**后，打开或唤出 App 时询问各门课的作业。填写后点击“保存作业并加入日程”，自动在未来 7 天找学习空档，保留原有安排；排不下的部分会列出原因。“稍后填写”保留当前内容，已填写的科目不重复问。等待时间和开关可在设置修改。

另一端更新记录后，使用“重新载入并保留未提交内容”，核对剩余科目再保存；另一端已填写的科目不会重复提交。课程被取消或调整时，其未提交文字会单独保留供查看和复制，不参与剩余科目的保存。保存失败时仍可“放弃本次输入并关闭”，此操作不依赖网络，有未保存输入时会先确认放弃。

功能规则、代码位置和后续优化方向见 [课后作业说明](docs/after-class.md)。

## 资料与运行方式

这份本机构建保留原项目位置标记。原项目目录存在时，复用它的 `.env` 和个人数据；不会把密钥、课表、作业或数据库打包进 App。若原助手已在相同资料目录运行，复用已有服务。端口被其他资料或程序占用时显示错误，不停止其他程序。

拷贝到没有原项目的 Mac 后，默认使用 `~/Library/Application Support/CampusCompanion`，需在设置重新配置模型。当前仅为本机 Apple Silicon 构建，未做 Intel 实机验收、开发者签名或 Apple 公证。

本地服务关闭或启动失败时，在桌宠菜单中选择“重新连接本机服务”。

## 开发与构建

需要 macOS 13 或更新版本、Xcode Command Line Tools，以及原应用的开发环境和已安装依赖。先按仓库根目录 README 准备后端、前端和生产扩展；后端环境需包含 desktop 依赖组（PyInstaller）。构建读取原项目的源码和生产课表扩展，重新构建前端；原应用已有的手动代码改动保留。

```bash
cd campus-pet
../backend/.venv/bin/python build.py
```

只修改 Swift、桥接脚本或角色图片时，复用本项目已经打包的服务：

```bash
../backend/.venv/bin/python build.py --reuse-service
```

改原后端或前端后，应执行完整构建，不使用 `--reuse-service`。先退出桌宠再替换构建中的 App。

## 验证

```bash
../backend/.venv/bin/python verify.py
```

使用专用端口 5189 和临时 SQLite，不占用日常 5173 服务，不读取个人模型配置或调用付费模型。覆盖原生 WebKit 会话、真实任务草稿确认、页面切换、Deep Agents 配合明确测试模型的流式聊天/自然语言草稿/审批恢复、状态动画桥接、隐藏/恢复、屏幕边界和关闭面板。结果及截图保存在 `build/verification/`。

原生验收还会检查二级退出菜单、取消停止，以及最后安全停止它自己的测试服务。逻辑回归可运行 `../backend/.venv/bin/python tests/run_native_tests.py`。浏览器回归使用 `frontend/playwright.pet.config.ts`、独立端口 5290 和系统 Chrome 的临时会话；先构建前端，再运行 `npx playwright test --config playwright.pet.config.ts`。

程序自动快照与真实鼠标拖动、多个物理显示器、睡眠唤醒是不同验证范围；后者需实机交互验收。不会把程序动画描述为生成了逐帧动作素材。

录制可复现的功能演示：`../backend/.venv/bin/python record_demo.py --seconds 60`。该脚本复制独立演示 App，在专用端口 5189 启动临时资料，自动运行任务环、详情、完成与补位流程，并调用 macOS 系统录屏保存 `build/recording/Demo2.2-raw.mov`；录屏需系统屏幕录制权限。请先结束原生验收，两个流程不能并行。不会录入声音或个人资料；这是自动功能演示，不能替代真实鼠标和多显示器验收。

## 形象来源

参考用户指定的 [Nailong-Studio/wallpaper](https://github.com/Nailong-Studio/wallpaper)，基于奶蛙的黄色圆润身体、浅腹、绿眼和灰爪制作。参考图与仓库许可保存在 `art/reference/`。原生成素材由内置 imagegen 制作，现保留为图标和回退形象。生成提示词与来源见 [art/character.md](art/character.md)。当前待机形象和三组动作直接提取自用户指定的哔哩哔哩视频，处理方式与片段时间见 [视频动作来源](art/video/README.md)。

## 课表与待办、日程的区别

- **课表**：只显示人工录入或导入并确认的课程，保留空白格和手工添加入口。课程是固定时间，智能安排不会修改或移动。
- **待办与日程**：包含待办管理、智能规划、固定课程参考、固定事项和学习时间块。先为待办补齐预计耗时或拆解步骤，再点击“智能安排未来 7 天”；程序根据课程、固定事项、学习窗口、截止时间与锁定安排避让冲突，校对确认后保存，排不下的任务说明原因。

课后作业的“查看日程”、固定事项保存后的跳转和未指定快捷目标的肚皮点击均进入“待办与日程”。两个界面共享同一份课程数据，不复制课程；变更课表后可重新规划，确认计划时会检查资料版本。原有作业询问、紫色提醒和快捷打开继续使用。
